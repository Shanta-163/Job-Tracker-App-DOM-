1. Differences Between Element SelectorsgetElementById: This targets a specific element using its unique id. It is highly efficient and returns only a single element object.getElementsByClassName: This targets all elements that share a specific class name. It returns a live HTMLCollection, which acts like an array and requires looping to manipulate individual elements.querySelector: This uses CSS selector syntax (e.g., #id, .class, div > p) to find elements. It returns only the first matching element it encounters.querySelectorAll: This also uses CSS selectors but finds all matching elements. It returns a static NodeList, which allows you to use the forEach method directly.
2. Creating and Inserting a New Element into the DOMTo add a new element to the DOM, you typically follow three straightforward steps: Use document.createElement('tagName') to generate the new element in memory.Content: Assign text or data to it using properties like innerText or textContent.Insert: Append it to an existing parent element in the DOM tree using appendChild() or append().
3. Event Bubbling and How It WorksConcept: When an event (like a click) happens on an element, it does not just stay on that specific element.Mechanism: The event starts at the exact target element that was clicked. Then, it bubbles up through its parent, grandparent, and continues all the way up to the document and window objects.Effect: If you click a button inside a div, and both have click listeners, the button's listener fires first, followed closely by the div's listener.
4. Event Delegation and Its BenefitsConcept: Instead of adding individual event listeners to many child elements, you attach a single event listener to their common parent element.Why it is useful:Memory Efficiency: Attaching one listener to a parent saves a lot of browser memory compared to attaching hundreds of listeners to individual child elements.Dynamic Elements: If you dynamically add new child elements to the parent later via JavaScript, they automatically inherit the functionality without needing new event listeners. You just check event.target to see which child was clicked.
5. preventDefault() vs. stopPropagation()preventDefault(): This stops the default behavior that the browser automatically performs for certain elements. For example, it prevents a link (<a>) from opening a URL or a form from reloading the page upon submission. It does not stop the event from bubbling up.stopPropagation(): This completely halts the event from traveling any further up the DOM tree. It prevents parent elements from capturing the event during the bubbling phase, but it does not stop the element's own default browser behaviors.
